# Bluetooth Smartphone RF Fingerprinting Database — Qualification

## Decision
**SECONDARY — optional cross-technology benchmark**

The published dataset describes Bluetooth RF signals from 27 smartphones across multiple manufacturers/models. It can test whether the feature/ingestion framework transfers to another wireless technology, but it is not a core WiFi/LoRa substrate.

Multi-day, receiver-variation and continual-learning suitability must not be assumed without package-level inspection.
