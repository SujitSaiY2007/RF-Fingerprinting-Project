# Bluetooth Smartphone RF Fingerprinting Database — Preliminary Qualification

## Identity

- Dataset: Database for the Radio Frequency Fingerprinting of Bluetooth Devices
- Dataset DOI: 10.5281/zenodo.3876140
- Intended D-stages: D3/D5; technology-diversity secondary benchmark
- Decision: **SECONDARY**

## Evidence

The dataset publication describes Bluetooth signals collected from 27 different smartphones spanning six manufacturers and several models. The dataset is publicly referenced through Zenodo and is reported as CC-BY.

## Qualification

The dataset is useful for demonstrating that the project can accommodate a second wireless technology and for testing RF fingerprint feature extraction on Bluetooth transient signals. However, it is not currently a core substrate for the project's WiFi/LoRa-centric validation plan.

The retrieved evidence does not establish sufficient multi-day, receiver-variation or continual-learning metadata for D7/D8. Those claims should not be made without direct inspection.

## Decision rationale

SECONDARY. Retain as an optional cross-technology validation source rather than a core dataset.
