# ORACLE — Dataset Qualification

## Decision
**SECONDARY — controlled benchmark**

## Responsibility
D2/D3/D5 and controlled distance/hardware-impairment robustness studies.

## Evidence summary
The GENESYS dataset provides raw OTA IQ from 16 USRP X310 transmitters with a fixed USRP B210 receiver, 2.45 GHz IEEE 802.11a operation and controlled transmitter-receiver distances. SigMF-compatible metadata is available.

## Strength
Useful for controlled investigation of whether RF-physics features remain device-informative under controlled hardware and distance conditions.

## Limitations
Small transmitter population, one primary receiver and limited ecological/domain diversity make it unsuitable as the core portfolio dataset.
